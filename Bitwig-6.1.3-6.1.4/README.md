# Bitwig Studio 6.1.3 and 6.1.4

This folder contains the twelve original 6.1.3 device builds using the
uncompressed Nitro format. The Nitro reader checks passed on 6.1.3 and
6.1.4. Full device compatibility in 6.1.4 still needs a host test.

Select this folder in Patchbay under **Tools → Device Folders**. Patchbay
scans subfolders recursively, so select only this folder for these devices.
